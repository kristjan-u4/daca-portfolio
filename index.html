Kristjan — Junior Data Analyst Journey

About Me & DACA

Hi! My name is Kristjan.

I recently completed the Data Analyst Career Accelerator (DACA) program, an intensive 11-week mentorship journey organized by Ettevõtluskeskus. Running from March 23rd to June 10th, 2026, the program simulated real-world data challenges using a fictional retail company named UrbanStyle Ltd.

As a software developer, I was already comfortable writing SQL queries for reports and using ORMs. However, I realized that I felt most fulfilled by analytical tasks and troubleshooting root causes. I joined the DACA program to transition into data analysis, learn how Python and Pandas are leveraged in this context, and discover how to integrate AI into modern analytical workflows.

Throughout this journey, I mastered advanced SQL techniques (such as CTEs and window functions), built interactive Streamlit dashboards with Plotly, performed customer segmentation using Pandas RFM analysis, and automated the entire workflow into a robust ETL pipeline.
